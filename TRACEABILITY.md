# TRACEABILITY

The number table lists every number in the main text of `report/draft.md` (Introduction to Part 5, outside code and citations) with the results files that hold a matching value (allowing for rounding, percentages, complements, sign and monthly or annual rescaling; up to four files per number, those with fewest values first). A file match shows that the value exists in that file, not that the file is the number's source: small numbers in particular match several files by coincidence. Literature figures listed in `report/cited_numbers.json` are credited to their source instead, and a whole number that matches nothing in `results/` but is on `src/check_numbers.py`'s allow-list of brief and design constants (word budgets, the seed, fold counts and the like) would be marked "allow-listed constant". The table is generated by `python -m src.trace_numbers` with the same extraction and matching as `src/check_numbers.py`; `run_all.py` regenerates it after every full run. Timing-derived numbers (minutes, g CO2e, fit-time ratio) change slightly from run to run.
